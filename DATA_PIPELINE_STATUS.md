## 📋 6. FRAUD DETECTION FEATURES (HYBRID APPROACH)

### Three-Layer Fraud Detection System

#### Layer 1: Tabular Anomaly Detection (IsolationForest)
```python
# Features used
- rent_price_etb: Raw rent price
- area_sqm: Property size
- price_per_sqm: Derived ratio
- subcity_rank: Market tier (1-10)

# Training
IsolationForest(contamination=0.05, random_state=42)
# Expects 5% of data are outliers (anomalies)

# Output: Percentile rank (0.0 = typical, 1.0 = extreme outlier)
```

**Anomalies Detected**:
- Unusually cheap properties for area (< 5th percentile)
- Unusually expensive properties (> 95th percentile)
- High price variance with same room configuration
- Extreme aspect ratios (rent/sqm)

#### Layer 2: NLP Text Suspiciousness (TF-IDF + Cosine Similarity)
```python
# Text processing
- Vectorize descriptions with TF-IDF (max 5,000 features)
- Compute centroids:
  * benign_corpus_centroid = mean(benign listing vectors)
  * scam_prototype_centroid = mean(hand-crafted scam examples)

# Scoring
- Cosine similarity to benign corpus
- Cosine similarity to scam prototypes
- Output: 0.0 (benign-looking) to 1.0 (scam-looking)

# Hand-crafted scam prototypes (only 5 examples)
"Send Western Union money",
"Pay Bitcoin immediately",
"Only accepting agent fee upfront",
"Pay full deposit in advance no viewing",
"Limited time offer incredible deal"
```

**Flags Detected**:
- Suspicious payment methods (Western Union, Bitcoin, gift cards)
- Urgency language ("limited time", "act now")
- Requests to pay without viewing
- Inconsistent descriptions
- Common scam phrases

#### Layer 3: Rule-Based Baseline (Deterministic)
```python
# Hard rules (no ML)
if "Western Union" or "Bitcoin" in description:
    score = 1.0  # FRAUD
if price < 0.2 * avg_price_for_area:
    score = 1.0  # SUSPICIOUSLY CHEAP
if deposit > 2.0 * monthly_rent:
    score = 0.8  # ABNORMAL DEPOSIT
if len(description) < 50 chars:
    score = 0.5  # VAGUE LISTING
```

### Final Fraud Score
```python
fraud_score = max(rule_score, isolation_forest_score, tfidf_score)
# Takes maximum across all three signals
# Critical heuristic flags never masked
# Returns breakdown for explainability
```

### Problems with Current Fraud Detection
- ❌ Only 5 hand-crafted scam examples (limited coverage)
- ❌ No labeled fraud/benign pairs from real platform data
- ❌ TF-IDF limited to benign/scam centroids (no supervised learning)
- ❌ No image analysis (property photos)
- ❌ No landlord profile history
- ❌ No account reputation scoring

## 📈 7. PROPERTY RECOMMENDATION ENGINE (RULE-BASED)

### Scoring System

**Input from tenant**:
- max_budget_etb
- preferred_subcities (list)
- min_bedrooms
- min_bathrooms

**Scoring across 4 dimensions** (total 100 points):

1. **Budget Fit** (35 points)
   ```
   If price <= budget: 35 pts (full)
   If price in [budget, budget * 1.3]: 35 * (1 - (price - budget) / (0.3 * budget)) pts
   If price > budget * 1.3: 0 pts
   ```

2. **Location/Subcity Match** (35 points)
   ```
   If subcity in preferred_subcities: 35 pts (full)
   If subcity adjacent to preferred: 25 pts (partial)
   Otherwise: 0 pts
   ```

3. **Room/Space Fit** (20 points)
   ```
   If bedrooms >= min_bedrooms AND bathrooms >= min_bathrooms: 20 pts
   Otherwise: 0 pts
   ```

4. **Furnishing Match** (10 points)
   ```
   If is_furnished matches preference: 10 pts
   Otherwise: 5 pts (partial credit)
   ```

### Adjacency Graph (Neighboring Subcities)
```
Bole ↔ Kirkos, Yeka
Kirkos ↔ Bole, Arada, Yeka
Arada ↔ Kirkos, Nifas Silk, Yeka
Yeka ↔ Bole, Kirkos, Arada, Nifas Silk
Nifas Silk ↔ Arada, Yeka, Gulele
Gulele ↔ Nifas Silk, Lidetta, Kolfe
Kolfe ↔ Gulele, Lidetta
Lidetta ↔ Gulele, Kolfe, Addis Ketema
Addis Ketema ↔ Lidetta, Akaky Kaliti
Akaky Kaliti ↔ Addis Ketema
```

### Constraint Relaxation
```python
if num_exact_matches < threshold:
    include top-scoring partial matches
    return explanations: "Slightly over budget (+8%)", "Nearby area (Kirkos instead of Bole)"
```

### Issues with Current Recommendation Engine
- ❌ Rule-based (no ML, cannot learn tenant preferences)
- ❌ No implicit feedback (not tracking clicks, acceptances)
- ❌ No collaborative filtering (similar tenant preferences)
- ❌ No personalization history

```python
def generate_data_quality_report(df: pd.DataFrame) -> dict:
    """Generate comprehensive data quality statistics."""
    return {
        "total_rows": len(df),
```

### Outlier Detection
```python
def detect_outliers(df: pd.DataFrame, column: str, method='iqr') -> pd.Series:
    """Detect outliers in a numeric column."""
    if method == 'iqr':
        Q1 = df[column].quantile(0.25)
        Q3 = df[column].quantile(0.75)
        IQR = Q3 - Q1
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR
        return (df[column] < lower_bound) | (df[column] > upper_bound)
    elif method == 'zscore':
        from scipy import stats
        z_scores = stats.zscore(df[column])
        return abs(z_scores) > 3
```

### Missing Value Analysis
```python
def analyze_missing_values(df: pd.DataFrame) -> pd.DataFrame:
    """Analyze patterns in missing values."""
    return pd.DataFrame({
        'column': df.columns,

        'missing_percent': (df.isnull().sum() / len(df) * 100),
        'dtype': df.dtypes,
```
